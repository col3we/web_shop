# Ardor Shop

## Описание:

Веб-магазин

## Установка:
 
1. Клонируйте репозиторий:
```
https://github.com/col3we/web_shop
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
# Использование:

## Описание функционала

- **Класс Product**: базовый класс для товаров. Реализованы:
  - Инициализация с параметрами: имя, описание, цена, количество.
  - Метод создания нового продукта из словаря.
  - Строковое представление.
  - Сложение объектов только одного класса.
  - Сеттер цены с проверкой и подтверждением снижения цены.
- **Класс Category**: класс для категорий товаров. Реализованы:
  - Инициализация с параметрами: имя, описание, список товаров.
  - Добавление товаров с проверкой типа.
  - Строковое представление.
  - Геттер для списка продуктов.
- **Классы Smartphone и LawnGrass**: наследники Product с дополнительными атрибутами.
- **Тестирование**: покрытие тестами всех основных сценариев.

## Тестирование:

7 тестов проверяются успешно в которых описаны разные случаи ввода пользователя
